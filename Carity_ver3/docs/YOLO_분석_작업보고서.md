### 2-3. 판단

- **n급은 YOLOv8n.** 효율은 세 모델이 13.0~13.1로 같지만, 근거리 차량 재현율이 v8n 0.78 vs 11n 0.68로 약 10%p 차이 납니다. 공식 COCO 순위(11n 우세)가 블랙박스 광각 영상에서는 뒤집혔습니다.
- **s급은 YOLO11s.** 정확도·속도 모두 v8s보다 낫습니다(+6.7점, -22ms). CPU에서는 7.8fps라 실시간에는 GPU가 필요합니다.
- **YOLOv5는 제외.** 원본은 같은 급 최하위이고, v5u는 v8 헤드를 쓴 개량판이라 따로 고를 이유가 없습니다.
- **오프라인 사전 라벨링은 YOLO11s.** 속도보다 정확도가 중요한 작업입니다.

### 2-4. 수치 해석 시 주의

- 122프레임이 5개 클립에서 나와 프레임 간 상관이 큽니다. 3%p 이내 차이는 오차로 봅니다.
- 기준 정답이 RT-DETR-x라 절대값보다 모델 간 순위로 해석해야 합니다.
- 속도는 클라우드 CPU 기준입니다. RTX 5060·차량 기기에서는 절대값이 달라집니다.

## 4. 이번 작업: 오프라인 정답 데이터 + 앱 판단 모듈

### 4-1. 구조

```
영상(7클립, 전방 1280×720 mp4)
 └─ prelabel_yolo.py : YOLO11s + ByteTrack, 10fps, conf 0.25
     └─ build_scenario.py
          ├─ OSD OCR(tesseract) → 자차 속도
          ├─ 평지 핀홀 근사 → 박스 하단의 전방거리 Z, 좌우 X (m)
          ├─ 트랙별 접근속도(Theil-Sen, 1.5초) → 역할 분류 (주차/대향/선행/횡단)
          └─ 전방 2.5~15m 주차차 안쪽 모서리 → 좌/우 여유폭, 도로폭
               └─ scenarios/<clip>.json  ──►  Android: RuleEngine + Qwen + Evaluator
```

### 4-2. 카메라 가정값 (캘리브레이션 전)

| 파라미터 | 값 | 근거 |
|---|---|---|
| 지평선 y | 0.53 | 075346/075433 도로 소실점 육안 추정 |
| 초점거리 f / 폭 | 0.384 | 수평화각 약 105도 가정 |
| 카메라 높이 | 1.30 m | 가정 |
| 보닛 끝 y | 0.82 | 프레임 육안 확인 |
| 자차 폭 | 1.85 m | 가정 |

좌우 거리 X = (u − cx) × h / (v − v_h) 이므로 **초점거리와 무관**하고, 지평선과 카메라 높이에만 민감합니다. 전방거리 Z는 초점거리에 비례하므로, 클립마다 주차차 접근속도 / 자차속도 중앙값(k)으로 척도를 자동 보정했습니다.

### 4-6. Qwen 연동 검증

- OpenAI 호환 모의 서버로 확인했습니다: HTTP 호출 → 코드블록으로 감싼 JSON 응답 파싱 → 결정 추출 → 평가 흐름 정상 동작.
- **실제 Qwen 정확도는 아직 측정하지 않았습니다.** PC(RTX 5060)에서 Ollama로 `qwen2.5:3b`를 띄운 뒤 `EvalCli` 또는 앱의 "검증 평가" 버튼으로 측정해야 합니다.
- 권장 모드는 `HYBRID`입니다. 규칙 결정이 최종이고, Qwen은 안내 문장 생성과 불일치 감시를 맡습니다. Qwen이 규칙과 다른 결정을 말하면 오해를 막기 위해 템플릿 문장으로 대체합니다.

## 5. 한계와 다음 단계 (우선순위 순)

1. **주행가능영역 seg 라벨링 (최우선).** 벽·연석을 못 잡아 좁은 길을 놓칩니다(075433). 150장 수작업 → YOLO11n-seg 1차 학습 → 사전 라벨 → 수정 반복.
2. **차량 방향 속성(front/rear) 추가.** 멈춰서 양보 중인 대향차는 속도로 구분할 수 없습니다. 앞면이 보이는 정지 차량이 진행 경로에 있으면 대향차로 처리합니다.
3. **카메라 캘리브레이션.** 주차칸 선이 보이는 정차 영상 10초로 호모그래피를 구하면, 지평선·높이 가정 오차를 없앨 수 있습니다.
4. **이벤트 50건 확보.** 현재 11건은 신뢰구간 ±25%p 수준입니다. 대향차 이벤트가 3건뿐이라 대향 판단 수치는 특히 신뢰하기 어렵습니다.
5. **정답 이벤트 팀 검수.** `events_gt.json`은 육안 검토 초안입니다. 특히 075433 28~34초(대향차가 양보 중)의 허용 결정을 팀이 합의해야 합니다.
6. **실제 Qwen 평가**와 규칙/Qwen/하이브리드 3모드 비교.
