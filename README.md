# Hyundai-PJT-On-sense-

기능 1. [시동 시점 (IG ON)] 0초 세팅! `CarInfo` 연동 자동 기준점 매핑

-> 메모리 저장 시트 존재 하지만, 운전자 시점에서 자동으로 맞춰주는 것 없음

(기각 -> 빈약 시 사용 예정, 렌트, 법인 -> 자차는 메모리 시트)

- **작동 맥락:** 운전자가 차에 타서 시동을 거는 순간(`Ignition` 상태 감지), 별도의 정차나 세팅 조작 없이 백그라운드에서 즉시 작동합니다.
- **Pleos API 활용:**
  - `CarInfo` API를 호출하여 내 차의 차종 코드를 식별하고, 매핑된 전폭(Width), 축거(Wheelbase), 운전석 시트 대비 대시보드(크래시패드) 형상 프리셋 데이터를 불러옵니다.
  - 인포테인먼트 운전자 프로필에 저장된 운전자 신장(예: $168\text{cm}$) 데이터와 결합하여, 운전자 눈높이에서 앞유리 하단 대시보드와 우측 차폭($50\text{cm}$ 여유선)이 만나는 **절대 기준점 좌표**를 자동 산출합니다.

### 기능 2. [위기 진입 직전] 디스플레이 '빨간 기준선' 점멸 & 현대 앰비언트 라이트 컬러 싱크(Sync)

-> 미존재 --> 정연 구현 + 채욱

좁은 골목길, 지하주차장 코너, 비포장도로에 진입하여 차량 속도가 $15\sim 20\text{km/h}$ 이하로 줄어들거나 초음파 센서(`Safety`)가 근접 장애물을 감지하면 시뮬레이션 모드가 깨어납니다.

- **시각적 기준점 각인:**
  1. 본격적인 주행 궤적 시뮬레이션을 띄우기 전(약 1.5초간), Pleos Connect 디스플레이 화면 속 대시보드 우측 기준점 위치에 굵고 선명한 **'빨간색 수직 기준선(Red Reference Bar)'**이 3회 깜빡(Blinking)입니다.
  2. **하드웨어 조명 동기화 (`Light` API):** 화면의 빨간 기준선이 깜빡이는 박자(0.5초 주기)에 맞춰, 실제 차량 내부의 **현대 앰비언트 무드라이트(크래시패드 및 조수석 도어 쪽 조명)가 동일한 빨간색(Red, `#FF0000`)으로 함께 깜빡**입니다.
  3. **효과:** 운전자는 화면을 오래 들여다보지 않아도, 화면 속 빨간 선과 실내 빨간 불빛의 위치 동기화를 통해 *"아, 지금 저 빨간 불빛이 깜빡이는 대시보드 우측 지점 안쪽으로 장애물이 들어오면 차가 긁히는구나!"*라는 공간 기준점을 1초 만에 직관적으로 인지합니다.

### 기능 3. [실제 코너 선회 중] 내륜차 스크래치 방어 ‘Zero-Look 조향각 보이스 코칭’ -> 판단 X, 삐삐빅 소리

-> 가영 누나 구현 + 채욱

초보자가 아파트 나선형 지하주차장 기둥이나 유럽 골목의 높은 돌 연석(Curb)에 뒷문짝과 뒷바퀴 휠을 긁는 이유는 **‘내륜차(앞바퀴보다 뒷바퀴가 안쪽으로 좁게 도는 현상)’** 때문입니다. 본격적인 코너 선회 중에는 운전자가 화면 대신 실제 도로와 사이드미러만 보도록 오디오 코칭이 주도권을 잡습니다.

- **작동 시나리오:** 차량 속도가 $15\text{km/h}$ 이하로 서행하며 골목 코너나 주차장 램프를 돌 때, `SteeringWheel`의 실시간 조향각($\theta$)과 `CarInfo`의 축거($L$) 데이터를 아래의 기하학적 회전 반경 공식에 대입해 뒷바퀴 안쪽 궤적을 0.1초 단위로 추적합니다.
  $$\text{내륜차 궤적 편차}(\Delta R) = L \cdot \left( \frac{1}{\sin\theta} - \frac{1}{\tan\theta} \right)$$
- **실시간 대화형 솔루션 (화면 볼 필요 없는 오디오 가이드):**
  - `Safety` API의 측후방 거리 경고 시그널이 울리기 직전, 현재 핸들 각도로 계속 전진하면 뒷바퀴가 연석이나 기둥에 닿는다고 판단되면 단순 "삐-삐-" 경고음 이후(동시가능) **구체적인 행동 지침**을 말해줍니다.
  - 🗣️ **CarTalk 보이스:** *"우측 뒷바퀴가 연석에 너무 가깝습니다. **핸들을 왼쪽으로 반 바퀴($180^\circ$) 풀고, 앞으로 $1\text{m}$만 더 나간 뒤** 다시 끝까지 꺾으세요."*
  - **3D 공간 오디오 패닝(Audio Panning):** 위험이 감지된 부위가 '오른쪽 뒷바퀴'라면, 차량 내 **우측 후방(조수석 뒷자리) 스피커에서만** 코칭 음성과 타악기 알림음을 출력하여 운전자가 전방을 보면서도 어느 쪽 차체가 긁힐 위기인지 본능적으로 인지하게 합니다.

### 기능 4. [한국 이면도로 & 유럽 골목 교행] 물리적 차폭 축소 ‘원터치 골목 패스(Alley Pass) 매크로’

찬영이 형 구현 + 민혁 (and 채욱)

-> 따로 없음 하지만, 앞에 물체 존재나 박을 위험을 있을 경우 자동 멈침 (20년식 이후)) -> 3가지 기능은 따로 없음 (급브레이크 시 자동 비상등은 존재 )

양옆에 차가 평행주차된 좁은 골목길에서 맞은편 차와 마주쳤을 때, 초보 운전자는 핸들을 잡은 손에 땀이 나며 사이드미러 접는 버튼이나 비상등 버튼을 찾을 여유조차 없습니다.

- **작동 시나리오:** 좁은 골목길에서 마주 오는 차량으로 인해 서행($10\text{km/h}$ 이하) 및 브레이크 반복 밟음(`Brake` API 감지)이 발생하고 전측방 근접 경고가 동시에 활성화될 때 작동합니다.
- **물리적 액추에이터 자동 제어 (Pleos API 연동):**
  1. **사이드미러 자동 폴딩 (`SideMirror` API):** *"좁은 골목 교행 구간입니다. 접촉 방지를 위해 양쪽 사이드미러를 잠시 접어 차폭을 $25\text{cm}$ 줄일게요."*라는 안내와 함께 미러를 자동으로 접어 물리적 충돌 확률을 즉각 낮춥니다. (교행 완료 후 속도가 $20\text{km/h}$ 이상 올라가면 자동으로 다시 펴짐)
  2. **현장음 청취 윈도우 개방 (`Window` API):** 유럽의 좁은 돌담 골목이나 한국 시장 골목에서는 보행자나 오토바이가 차체 바짝 붙어 지나갑니다. 조수석 창문을 자동으로 $3\text{cm}$ 미세 개방하여 외부 소리가 실내로 들리게 함으로써 사각지대 사고를 예방합니다.
  3. **매너 비상등 자동 점멸 (`Light` API):** 초보 운전자가 당황해 골목에서 거북이 주행을 하거나 길을 비켜줄 때, 음성 명령 한마디(*"카톡, 고맙다고 비상등 켜줘"*) 또는 정차 시 자동으로 비상등을 3회 깜빡여 뒷차와 맞은편 차의 경적(클랙슨) 스트레스를 줄여줍니다.

## 기능 5. 시뮬레이션 기능 (튜토리얼 기능)

민혁 (디지털 트윈)

좁은 골목길, 평행 주차된 길 등 다양한 협소한 상황에서 차량의 차폭을 계산해서 튜토리얼 제공 및 글레오 AI 음성을 통해서 어떻게 해야하는지에 대한 내용을 알려줍니다.

- **글레오 AI 음성 지원** : "좁은 골목길 상황에서 좌측에 얼마나 붙어있습니다. 핸들을 조정하세요"

- **엠비언트 라이트** : 좌측에 가깝거나, 우측에 가까울 경우 빨간색 그라데이션으로 강조하여 제공, 만약 안정적인 경우 초록색으로 제공하여 시인성 추가 증진

- **튜토리얼(시뮬레이션)화면 제공**: 現 기능의 경우 3D화면 제공 중, 하지만 튜토리얼(시뮬레이션) 화면을 제공하지는 않고 있습니다. 해당 기능은 플레오스 화면에서 띄워주면서 운전자에게 제공, 하지만 운전 집중도나 분산도 저하 우려 존재로, 글레오 AI 음성 지원과 엠비언트 라이트를 제공으로 분산도 저하 우려 개선 (이 기능의 경우 디지털 트윈으로 구현 예정)

### 튜토리얼 기능 구성 요소

협소한 길, 앞에 차량과 대면 상황 -> AI 판단 (구현 시 외부 API로 구현, 기획서 작성 시 현대 그룹 LLM 사용으로 작성) -> Solution 제공 (튜토리얼 및 글레오 음성 AI) -> 운전자 판단 후 주행
