# Alley Pass 3D 시연 가이드

최종 갱신: 2026-11-13 · Pleos Connect v2.1.0 · debug 에뮬레이터 전용

## 현재 구성

오른쪽 앱 영역 안에서 왼쪽70%는 골목·주차 차량6대·내 차의3D, 오른쪽30%는 팀원 On-sense 구성을 옮긴 차량 정보 패널이다. 공통 상단 안내와 하단 D/R/N/P·시연·매크로 버튼을 유지한다. 왼쪽 Pleos 기본 차량 영역은 침범하지 않는다. 맞은편 차량은 없다.

차량 정보 패널은 기존 구독을 공유하여 실제 AAOS 속도·기어와 Pleos 조향 원본값·브레이크를 표시한다. 실제 수신이 없거나3초 이상 지연되면 --로 표시한다. 가상 자동 시연 중에는 '실제 SDK 값 · 3D는 가상 시연'으로 구분한다. 팀원의 자동 Activity 전환·음성·점멸은 이번 통합에 포함하지 않았다. 변경 파일·검증은 개발 진행상황22절 참고.

실제 AAOS 속도·기어와 Pleos 브레이크·조향을 수신한다. 주변 차·벽·간격·매크로 동작은 가상 데이터다. 화면의 측면 경고 색상은 실제 앰비언트 라이트가 아니다.

## 앱에서 키보드로 Console 조작

1. 속도0·P단에서 앱을 Pleos 런처로 연다.
2. 다른 Virtual Console 브라우저 탭과 PC 시나리오 실행기를 종료한다.
3. 하단 'Console 키보드 연결'을 누르고 연결·SDK 수신을 기다린다.
4. D를 한 번 누른다. 계속 누르고 있을 필요가 없다.
5. 에뮬레이터 앱에 키보드 포커스를 두고 아래 키로 조작한다.
6. 정차 후 P를 눌러 시스템 화면과 앱에서 P단을 확인한다.

| 입력 | 동작 |
| --- | --- |
| D / R 버튼 | 정차 상태에서 전진/후진 기어 선택. 선택 상태 유지 |
| ↑ | 선택한 D/R 방향으로 가속. 시연 최고6km/h |
| ↑ 해제 | 관성 이동하면서 자연 감속 |
| ← / → | 속도가 있으면 곡선 이동. 0이면 조향각만 변경 |
| 좌우 키 해제 | 다음 Console 전송 주기에 중앙 복귀 요청. 실제 이동은 SDK 수신 후 반영 |
| ↓ | 브레이크. 가속과 동시에 누르면 브레이크 우선 |
| Space | 에뮬레이터 속도0 요청 |
| N 버튼 | 중립. 움직이는 중 누르면 관성 감속하며 즉시 정지는 아님 |
| P 버튼 | 정차 확인 후 주차 기어 선택 |
| R 키 | P단 확인 상태에서 시연 위치 초기화·재연결. R 기어 버튼과 다름 |

D/R/P 전환은 최신 SDK 속도와 Console 속도가 정지인지 확인한다. 미수신 상태에서는 허용하지 않는다.
R 기어는 구현했으나 이번 실기 시험에서는 포커스 상실로 연결이 정리되어 연속 후진 검증은 남았다.

키보드 입력 경로:

```text
키보드 → 앱의 시연 입력 모델 → 에뮬레이터 내부 localhost:8088 Console
                              → Pleos 시스템 차량 정보
                              → AAOS 속도·기어 / Pleos 브레이크·조향
                              → 앱의 가상 위치·차체 간격·3D 경고
```

가속페달 값과 속도값을 함께 Console에 전송한다. 페달만으로 실차 물리 엔진의 속도를 생성하는 시험은 아니다. 앱의 이동에는 SDK로 돌아온 값을 사용한다. Console은 정수 km/h를 받으므로 표시 속도는 단계적으로 바뀐다.

화면 이탈·포커스 상실·가상 접촉·연결 오류 시 입력을 해제하고 속도0·P단 정리를 시도한다. 연결이 끊기면 정리를 보장할 수 없으므로 Console 상태를 확인한다. 정상 정리 로그는 STOP_VERIFIED speed=0 gear=P다.
이후 P단에서 'Console 키보드 연결'로 다시 시작한다. PC 키보드가 앱에 전달되도록 에뮬레이터 키보드 설정·창 포커스를 확인한다.

Console HTTP 인터페이스는 현재 에뮬레이터 내부 구현이며 공식 차량 SDK 제어 API가 아니다. debug 에뮬레이터에서만 사용한다. release에 인터넷·cleartext 설정을 추가하지 않았다.

## 매크로 확인

1. 가상 주차 차량 근처1.2m 이내에서 저속으로 브레이크를15초 내3회 눌렀다 놓는다.
2. ↓로 충분히 감속하여 정지한 뒤 P 버튼을 누른다.
3. 앱과 Console의 P단·정차가 확인되고 UX 제한이 해제되면 '패스 매크로(SIM)'를 누른다.
4. 하단 확인창에서 '가상 실행'을 누른다.
5. 상단에 미러 → 조수석 창문 → 비상등3회 → 완료 카드가 하나씩 표시된다.

P단이 확인되면 브레이크 키를 계속 누를 필요는 없다. 감지 유효시간은30초다. 가상 접촉·급박한 근접은 매크로보다 우선한다. 조건 상실 시 확인·실행을 취소한다.

미러·창문 각2.2초, 비상등0.5초 ON/OFF3회, 약7.6초 후 완료한다.
실제 미러 접기·3cm 창문 개방·비상등 점멸·차폭25cm 감소를 구현 성공으로 표시하지 않는다. 실제 액추에이터 호출은0이다.
매크로 뒤 새 운전은 P단에서 'Console 키보드 연결'로 다시 시작한다.

## 앱 내부 자동 시연

'자동 시연(가상)'은 앱 내부 가상 속도·브레이크로 약10초 시연한다. Console 차량 상태를 변경하지 않는다.
정차 후 매크로 버튼·확인창으로 같은 단계 안내를 재생할 수 있다.
'초기화'는 위치·감지 이력·확인창·진행 중 매크로를 초기화한다.

## 기존 PC Console 자동 시험

Node.js18 이상·adb가 필요하다. 앱 키보드 모드와 동시에 실행하지 않는다.

```powershell
node tools/console-scenario.mjs --run tools/scenarios/left-approach.json
node tools/console-scenario.mjs --dry-run tools/scenarios/left-approach.json
node tools/console-scenario.mjs --probe
node tools/console-scenario.mjs --prepare
node tools/console-scenario.mjs --stop
```

실행 전 앱을 Pleos 런처로 열고 초기화한다. 카운트다운 중 'SDK 연동 시작'을 누른다.
PC 도구가 Console 세션·DDS 연결을 유지하고 시간표대로 속도·페달·조향을 재생한다. 종료 시 정차·P단 재조회와 기존 AVD 연결 모드 복원을 시도한다. 강제 종료·연결 단절 시 정리는 보장하지 않는다.
맞은편 차량 시나리오 oncoming.json은 삭제했으므로 실행하지 않는다.

## 거리 계산

속도×시간과 저속 자전거 모델로 가상 위치·방향을 갱신한다. 내 차 이동을 최대 약8cm씩 나눠 검사한다.
차체는 폭1.8m·길이4.2m 직사각형, 도로 폭7m·휠베이스2.7m를 가정한다.

모서리 네 점만 비교하지 않는다. 왼쪽·오른쪽·앞·뒤 선분 전체와 주차 차량의 모든 변 사이 최소 간격을 계산한다.
교차 시0, 그 외에는 양쪽 선분 끝점에서 상대 선분까지 거리의 최솟값을 사용한다. 전체 겹침은 SAT 검사로 판정한다.
작은 장애물이 측면 중앙에 있어도 검출한다. 실제 센서 측정·차종별 미러 돌출 제원은 포함하지 않는다.

직진·왼쪽·오른쪽 후보를 현재 속도로2.5초 진행해 최소 여유를 비교한다.30cm 이하 또는 모든 후보의 여유45cm 미만이면 정차 안내를 우선한다.
운전자 반응·타이어 미끄러짐·실차 조향 보정은 포함하지 않는다. 통과 가능성을 보장하지 않는다.
상세 식과 단위는 [개발 진행상황](Alley_Pass_개발_진행상황.md)의 계산 절 참고.

## 검증 범위

- 최신 Android44개 테스트 통과, 실패0. debug 빌드·에뮬레이터 배포 완료. Node2개는 이전 통과 기록이며 이번 변경 대상 아님.
- 방향키 → Console → 왼쪽 Pleos D·6km/h 표시 및 앱 SDK 이동·근접 경고 확인.
- 조향 좌우 반전 수정·1초 램프 제거 후 ← 왼쪽 곡선/→ 오른쪽 곡선 실기 확인. SDK 원본을 유지하고 모델용 좌표 부호만 변환. 수신 전 키 입력으로 이동을 예측하지 않음.
- Console 조향 요청→SDK 수신18ms·32ms 표본, 중앙 복귀220ms 표본 관찰. 전체 입력·화면 지연의 보장값은 아님.
- SDK 브레이크3회 → 정차·P단 → 확인창 → 가상 실행 완료 확인.
- 완료 로그: SIMULATION_COMPLETED; actuatorWrites=0.
- R 연속 후진·N 주행 중 전환·PC 물리 키보드 동시 입력은 실기 추가 확인 필요.
- 한국어 TTS 준비 실패로 실제 음성 출력 미검증. 팀 음성 모듈 통합·실내 조명·실차 검증은 남음.

최신 변경 파일과 과거 기록은 [개발 진행상황](Alley_Pass_개발_진행상황.md)21절·20절에 정리했다.
