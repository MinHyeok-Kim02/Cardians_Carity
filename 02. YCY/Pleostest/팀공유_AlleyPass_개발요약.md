# Alley Pass 개발 현황 요약

기준: 2026-11-12 / Pleos Connect Emulator  
사용 SDK: Vehicle 2.3.2, FusedLocation 1.1.3 / 속도·기어는 AAOS 표준 API 사용

## 1. 실제 확인한 조회·제어 결과

**제어 성공은 앱의 변경 요청 → 별도 상태 재조회 → 원래값 복원까지 확인한 경우다.**
완료 콜백만 수신한 경우는 성공으로 처리하지 않았다. 모두 에뮬레이터 검증이며 실차 검증은 아니다.

| 기능 | 조회 결과 | 실제 제어 결과 |
| --- | --- | --- |
| 속도·기어 | AAOS로 속도 갱신·P단 조회 확인 | 조회 용도로만 사용 |
| 브레이크 | Pleos SDK로 눌림·해제 수신 | 조회 전용 |
| 조향각 | Pleos SDK 수신 및 가상 차량 움직임 연동 확인 | 실제 차량 조향 제어 없음 |
| 위치 | FusedLocation 콜백 수신 확인 | 조회 용도로만 사용 |
| 사이드미러 열선 | 단계 조회 성공 | **0→1→0 변경·복원 성공** |
| 앰비언트 스위치 | 상태 조회 성공 | **OFF→AUTOMATIC→OFF 모드 변경·복원 성공**. ON 점등은 미시험 |
| 앰비언트 밝기·색상 | 현재값 조회 성공 | 완료 응답은 왔으나 조회값 유지 → **적용 미확인** |
| 창문 위치 | 4개 창문 조회 성공, 범위0~10 | 조수석 변경 요청 후 조회값 유지 → **적용 미확인** |
| 도어 위치·잠금 | 위치·묶음 잠금 상태 조회 성공 | 변경 요청 후 값 유지. 개별 조수석 잠금은 영역 미지원 오류 → **제어 미확인** |
| 공조 설정온도 | 설정22℃·현재19.1℃ 조회 성공 | 23℃ 요청 후 조회22℃ 유지 → **적용 미확인** |
| 공조 풍량 | 3단계 조회 성공, 범위1~8 | 4단계 요청 후 조회3 유지 → **적용 미확인** |
| 공조 냉방·전원 | 켜짐 조회 성공 | 제어 미시험 |
| 창문·글로브박스 잠금 | 상태 조회 성공 | 제어 미시험 |
| 방향지시등 | 읽기 Capability 확인 | 확인한 SDK에 쓰기 API 없음 |
| ETCS 음량 | 현재 장치에서 속성 미지원 오류 | 제어 미시험 |

추가 확인 사항:
- 미러 **접기·펴기**, **비상등 작동**, **주변 장애물 거리** API는 현재 확인한 Vehicle 2.3.2 공개 인터페이스에서 찾지 못했다.
- 앰비언트 쓰기는 인터페이스 주석과 달리 실제 구현에서 CONTROL_CAR_LIGHTS 권한을 요구했다.
- 좌석·충전·와이퍼 등은 API 존재만 조사했으며 실제 제어 성공을 확인한 것은 아니다.
- '적용 미확인'은 영구 미지원이라는 뜻이 아니다. 장치·모드·Console·SDK 상태 반영 원인은 추가 조사 필요.

## 2. 가장 최근 구현: 가상 골목 주행 시뮬레이션

- 수동 거리 입력을 없애고 **주차 차량6대와 골목 경계가 있는 가상 환경** 구성.
- 실제 수신한 **속도·조향**에 따라 가상 내 차의 위치·방향이 변하고 차체 간 거리 계산.
- 접근·근접 경고 표시, 가상 접촉 시 시뮬레이션 정지.
- 사용자 Console 조작으로 이동·조향 반영 및 왼쪽 주차 차량 접촉 경고까지 확인.
- SDK 점검 UI 제거. **왼쪽 차량 기본 정보 영역을 유지하고 오른쪽 앱 창에만 표시**.
- 빌드 성공, 전체 테스트 **12개 통과 / 실패0**.

**중요:** 골목·주차 차량·계산 거리는 모두 가상이다. 실제 주변 차량을 감지하는 기능은 아니다.
조향은 시연용 모델에 매핑했으며 실제 차량 물리 보정값이 아니다.
주행 시연용 DO 설정은 debug 빌드에만 적용했고, 주행 제한 중 시작·초기화 버튼은 잠근다. 출시 주행 허용 검증은 별도다.

### 시연 방법

Pleos 앱 라이브러리에서 앱 실행 → P단에서 '처음 위치로' → '시뮬레이션 시작' → Virtual Console에서 D단·저속 가속·조향 조작.  
가상 접촉 후 다시 시험하려면 P단에서 초기화한다.
